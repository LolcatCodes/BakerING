# BakerING plugin updates

Custom IntelliJ plugin repository for BakerING (not distributed via the JetBrains Marketplace).

## Install / add the update source

In your IDE: **Settings → Plugins → ⚙️ (gear icon) → Manage Plugin Repositories → +**, then add:

```
https://raw.githubusercontent.com/LolcatCodes/BakerING/main/updatePlugins.xml
```

The plugin will then appear under *Marketplace* (search "BakerING") for install, and future versions will show up as regular updates.
